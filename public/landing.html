Run it yourself · Windows, macOS or Linux

Runs on your machine.

The model runs inside your browser, so there is no server to host. Set it up once, then it works without internet.

  1. Install Node.js 20.9 or newer and Git.
  2. Download the code. git clone https://github.com/Ortholm10/OraTrace.git && cd OraTrace
  3. Install dependencies. npm install
  4. Create a file named .env in the folder with the sign-in keys (values in the submission notes). NEXT_PUBLIC_SUPABASE_URL=… NEXT_PUBLIC_SUPABASE_ANON_KEY=…
  5. Build and start, then open localhost:3000 and sign in once while online. npm run build && npx serve out
